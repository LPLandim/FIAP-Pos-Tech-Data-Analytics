## 🏆 Destaque: Fase 1 Concluída!

A documentação detalhada, notebooks em Python, relatório executivo e o certificado de conclusão da **Fase 1** podem ser acessados diretamente na pasta:

👉 **[Acessar Fase 1 - Data Analytics](Fase%201%20-%20Data%20Analytics/)**

* **Tema do Projeto**: Diagnóstico Comercial, Logístico e de Experiência do Cliente na base brasileira de e-commerce da Olist (~100 mil pedidos).
* **Entregas**: Tratamento avançado de dados em Python, análise exploratória, identificação do gargalo logístico vs. notas de satisfação, diagnóstico de recompra (3%), e proposta de modelo de assinatura com plano de ação executivo para acionistas.

---

## 🛠️ Tecnologias & Ferramentas Utilizadas

* **Linguagens**: Python 3.10+
* **Bibliotecas**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
* **Ambientes**: Jupyter Notebook, VS Code
* **Gestão e Métodos**: Análise Exploratória de Dados (EDA), Métricas de Negócio (CAC, LTV, CSAT, Ticket Médio, Lead Time), Relatórios Executivos e Storytelling com Dados
